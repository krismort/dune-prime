# Dune Prime 0.1.0 - Initial Engine Source Release

The initial release of the portable Dune Prime engine source, licensed under MIT.

The attached source archive includes the engine, launcher, build scripts, documentation,
tests and vendored third-party source with its licences. Game files, extracted game
assets, captured fixtures, saved games and mod packages are excluded.

Players supply `DUNE.DAT` and `DNCDPRG.EXE` from their own Dune CD version 3.7.
Setup instructions are included in the engine source archive.

## Download and build

Download `DunePrime-0.1.0-source.tar.gz` and its `.sha256` sidecar. Install a C/C++ compiler,
make, pkg-config and SDL2 development files, extract the archive, then run `make`.
The archive's README explains platform builds and optional tests using your own game data.

This initial release provides source. Application packages will be attached separately
when published. GitHub's automatic Source code ZIP/tar links contain only this public
repository's release documentation; use the attached engine source archive.

## Verification

- Engine source audit and five source-packaging regression tests passed.
- The engine compiled on macOS without game data or a mod checkout.
- Synthetic extension, dialogue and shared-window checks passed.

# Dune Prime 0.1.0 - Initial Engine Release

Portable Dune Prime engine applications for macOS, Windows and Linux, plus the MIT-licensed engine source.

| Platform | Download | Start |
|---|---|---|
| macOS 11+, Apple silicon and Intel | [Universal DMG](https://github.com/krismort/dune-prime/releases/download/v0.1.0/DunePrime-0.1.0%2B22ea583b8-macos-universal.dmg) | Open the DMG and drag Dune Prime to Applications |
| Windows 10+, x64 | [Installer](https://github.com/krismort/dune-prime/releases/download/v0.1.0/DunePrime-0.1.0%2B22ea583b8-windows-x64-setup.exe) or [portable ZIP](https://github.com/krismort/dune-prime/releases/download/v0.1.0/DunePrime-0.1.0%2B22ea583b8-windows-x64.zip) | Install per user, or extract the ZIP and run dune-prime.exe |
| Linux x86_64 | [tar.gz](https://github.com/krismort/dune-prime/releases/download/v0.1.0/DunePrime-0.1.0%2B22ea583b8-linux-x86_64.tar.gz) | Extract, install SDL2, run ./dune-prime |
| Linux arm64 | [tar.gz](https://github.com/krismort/dune-prime/releases/download/v0.1.0/DunePrime-0.1.0%2B22ea583b8-linux-arm64.tar.gz) | Extract, install SDL2, run ./dune-prime |

Linux packages require glibc 2.36 or newer and SDL2 (`sudo apt install libsdl2-2.0-0` on Debian/Ubuntu).
The macOS app is ad-hoc signed, not notarized. Windows packages are unsigned.

## Bring your own game

Every application is engine-only. Players supply `DUNE.DAT` and `DNCDPRG.EXE` from their own
Dune CD version 3.7. The included `DUNECD/COPY-GAME-HERE.md` explains the supported files and locations.
No original game files, extracted assets, captured fixtures, saves or mod packages are included.

## Source and verification

Engine source: [source archive](https://github.com/krismort/dune-prime/releases/download/v0.1.0/DunePrime-0.1.0-source.tar.gz). GitHub's automatic Source code ZIP/tar links contain the release repository metadata; use the attached engine archive.

All apps use engine source commit `22ea583b88d175986685eeee85e75807d43f9316` (development tag `v0.1.0`), and report build `22ea583b8` without a dirty suffix.

- macOS: both Mach-O architectures, code signature, packaged launch and a private local game frame checked; actual read-only DMG contents audited.
- Windows: ZIP and extracted NSIS installer payloads audited; packaged executable successfully launched on Windows Server 2022.
- Linux: both packages built and launched on native x86_64 and arm64 Debian 12 runners; archive contents audited.
- All application packages were independently inspected again before upload. No game data or mods were sent to hosted build runners.

The source audit and source-packaging regression tests passed. GCC builds pre-include the standard algorithm header to accommodate a missing explicit include in this initial source snapshot; the tagged source files are unchanged. The build recipe and per-platform verification are recorded in this repository.

[SHA256SUMS](https://github.com/krismort/dune-prime/releases/download/v0.1.0/SHA256SUMS) lists all download checksums. The original engine source archive and its separate checksum are unchanged.

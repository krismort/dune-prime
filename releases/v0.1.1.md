# Dune Prime 0.1.1 — re:cade storefront handoff

This release adds the versioned metadata and v1 bundle required for re:cade to present Dune (Prime), its download options and its launcher image.

Linux requires glibc 2.36 or newer and SDL2 (`sudo apt install libsdl2-2.0-0` on Debian/Ubuntu).
The macOS app is ad-hoc signed, not notarized. Windows packages are unsigned.

## re:cade integration

- [recade.game.json](https://github.com/krismort/dune-prime/blob/v0.1.1/recade.game.json) is committed in this release's tagged public tree. It provides the title, description, author, category, genre, platforms, licence, controls, original-game requirements and separate author credits. It has no version field.
- [recade-release.tar.gz](https://github.com/krismort/dune-prime/releases/download/v0.1.1/recade-release.tar.gz) contains recade.json, the four required platform/architecture packages, and a clean engine-launcher PNG with meaningful alt text and caption. It contains no root descriptor, source archive, game files, saves, mods or workbench material.
- The bundle version matches this stable tag and VERSION. Each package and screenshot has a SHA-256 recorded in the bundle.

The bundle is compatible with the existing manual re:cade native importer. An operator can import this exact release with `npm run deploy -- dune-prime --github-release v0.1.1`. Creating the upstream metadata does not enable the automatic storefront watcher, which is a separate re:cade implementation/configuration step.

## Engine-only distribution

Players supply DUNE.DAT and DNCDPRG.EXE from their own Dune CD version 3.7. The launcher and included COPY-GAME-HERE instructions explain where to put them. No original game data or mods are included.

All application packages are built from the same private engine tag/commit, report `0.1.1 (build f85790a1a)`, and passed package audits and native launch checks. The missing C++ standard header is now included explicitly, so GCC builds no longer need the prior compiler workaround.

Engine source remains private and is not an asset of this release. GitHub's automatic source archives contain only this public repository's metadata. [SHA256SUMS](https://github.com/krismort/dune-prime/releases/download/v0.1.1/SHA256SUMS) covers every attached release asset.
